# mobileapp

HTML / CSS / JavaScript で作成した小さな Web アプリ集です。`index.html` をブラウザで開くと、各アプリへのリンク一覧が表示されます。

## アプリ一覧

| フォルダ | 内容 |
|---|---|
| `01_omikuji` 〜 `01_omikuji4_kimetsu` | おみくじ（4 バージョン） |
| `02_calculator_v1`, `02_calculator_v2`, `03_calcuator_v3` | 電卓 |
| `04_memo`, `04_memo_app_v1` 〜 `04_memo_app_v3` | メモアプリ |
| `05_tic tac toe_06_sound` | 三目並べ（サウンド付き） |
| `06_tic tac toe vs computer` | 三目並べ（コンピュータ対戦） |
| `07_tic tac toe vs computer level` | 三目並べ（コンピュータ対戦・レベル選択） |
| `98_Time guessing quiz` | 時間当てクイズ |

## 使い方

ビルドは不要です。リポジトリをダウンロードし、`index.html` をブラウザで開いてください。
